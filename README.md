# 🎓 Campus Connect – Student & Faculty Interaction Platform

## 📌 Project Overview
Campus Connect is a web-based platform designed to improve communication and interaction between students and faculty within a campus. It provides dedicated dashboards, real-time updates, and an organized system for academic collaboration.

---

## 🚀 Features

### 👨‍🎓 Student Dashboard
- View announcements and updates
- Access academic information
- Interactive interface for students

### 👩‍🏫 Faculty Dashboard
- Post announcements
- Manage student interactions
- Update academic content

### 🔐 Authentication System
- Firebase-based login system
- Secure user authentication

### ⚡ Performance Enhancements
- Preloading screens for faster UX
- Smooth navigation between pages

---

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend / Services
- Firebase (Authentication & Database)
